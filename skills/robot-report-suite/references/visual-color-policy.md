# 报告中的少量彩色图片策略

## 基本分工

实验报告的技术逻辑由黑白文字、表格、流程图、结构图和曲线承担；彩色图片只补充实物、场地、视觉系统画面或用户给出的固定模板素材。不要把报告改造成 PPT，也不要让颜色成为状态、优先级或结果的唯一编码。

## 允许范围

1. 默认保留模板原有的彩色校徽、logo、官方插图和用户提供照片；不重新着色。
2. 对八页左右的报告，通常最多新增 1—2 张彩色图片，或使新增彩色图片的总版面不超过新增图形面积的约 20%。用户指定的模板或课程要求优先。
3. 允许的新增彩色图片：已知来源的实物/现场照片、相机原始画面、用户确认的屏幕截图，或清楚标为“解释示意，非实测”的生成图。
4. 禁止的新增彩色内容：彩色文字、彩色底纹、渐变卡片、装饰色块、无来源的性能曲线、彩色流程/状态卡，以及会使数据只能靠红绿等颜色辨认的图。

## 单图登记与图注

每张新增彩色图都在 `manifest.json` 或图形卡片中记录：

```text
图号：
类型：原始彩色证据图 / 解释示意图
原始文件或生成提示词：
来源与时间：
能证明：
不能证明：
本报告新增彩色图序号：n / 总预算：
```

图注要写明材料身份，例如“图 4-2 车载相机原始画面（用户提供）”或“图 5-1 协同场景解释示意（生成图，非实测）”。如果图片来自生成工具，不能生成可读的仪表数值、实验结果、校徽或现场认证标志。

## 版式与验收

- 彩色图片用于一个明确的观察点；相邻页不要连续堆放同类彩照。
- 保持原始纵横比，必要时只裁去无关背景；不得美化或重画测量读数、识别框、日志内容。
- 图内外仍使用黑色图题和正文；彩照旁配黑白流程图、表格或文字说明，确保灰度打印时结论仍然可读。
- 格式审计除彩色字体/底纹外，还检查彩色图的数量、来源与证据边界；不满足时改为黑白、删除或降级为待补材料。
