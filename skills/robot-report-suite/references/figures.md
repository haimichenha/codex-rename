# 图形制作规则

## 图形选型

| 需求 | 首选 | 源文件 | 导出物 |
| --- | --- | --- | --- |
| 控制流程、蓝牙命令状态、串口交互时序 | Draw.io | `.drawio` | 嵌入 XML 的 `.svg` + `.png` |
| 模块、引脚、数据流、通信拓扑 | Draw.io | `.drawio` | 嵌入 XML 的 `.svg` + `.png` |
| 无 Draw.io 时的简洁流程/时序 | Mermaid | `.mmd` | `.svg` + `.png` |
| 无额外安装的结构关系图 | Graphviz | `.dot` | `.svg` + `.png` |
| PWM 阶跃、角度、速度、串口时间序列 | Matplotlib | `.py` + `.csv`/日志摘录 | `.svg` + `.png` |
| 照片上的接口或部件说明 | 原始图片 + 标注脚本/记录 | 原图 + 标注说明 | `.png` |

Draw.io 提供更适合 Word/PPT 修订的可编辑流程和结构图；Mermaid 适合 Git 友好的简洁过程和时序图；Graphviz 是当前零新增安装的拓扑回退；Matplotlib 只绘制具有明确数据来源的数值图。它们不能替代真实接线图、示波器波形或实测照片。完整的证据门与后端选择见 `figure-workflow.md`。

## 默认视觉：论文黑白技术图，少量彩色证据图片

除非模板或用户明确要求颜色，新增图统一为：白色画布、黑色文字、黑色边线/箭头，必要时仅用黑白虚线、线宽、节点形状和编号表达层次。不得使用彩色圆角信息卡片、渐变、装饰色条或只依靠颜色区分状态。

- **流程图/树图**：应包含输入、判定条件、分支、异常/超时出口、输出或复位；不要只画“开始—处理—结束”。
- **结构图**：标明模块边界、方向、接口/数据名和必要单位；用实线/虚线区分数据与控制，而非颜色。
- **表格**：优先模板样式；无模板时采用白底黑线三线表/单线表，表头加粗而不填彩色底纹。
- **实物图**：保留原图，不做“美化式”重绘；黑白箭头/编号标出与正文有关的接口即可。

少量彩色图片仅按 `visual-color-policy.md` 作为实物、现场、相机画面或明确来源的证据插图；它们不能替代流程/结构图，不能加入彩色信息卡、渐变、伪数据或使读者必须靠颜色理解结论。

## 每幅图的交付合同

```text
图号：图 3-2
标题：蓝牙动作命令到舵机执行的数据流
类型：结构图 / 流程图 / 实测曲线 / 实物照片
源文件：figures/source/fig_3_2.mmd
导出文件：figures/export/fig_3_2.svg, fig_3_2.png
输入来源：代码模块路径、串口日志、用户提供照片...
图中事实状态：实测证据 / 用户确认 / 设计示意
色彩类型与预算：黑白技术图 / 原始彩色证据图 / 明确标注的解释图；本报告第 <n> 张新增彩色图
图注允许得出的结论：
限制：
```

## 信号图最低要求

对 PWM、UART、姿态角或控制量，至少标明：横轴及单位、纵轴及单位、采样或估计方式、测试条件、数据文件或日志范围。若波形由算法模拟而非实测，图题必须写“仿真/示意”。

## 版式

- 优先 SVG/PDF 等矢量图；为 Word 兼容可同时提供 200–300 DPI PNG。
- 同一章节统一字体、线宽、箭头和图例；技术图保持黑白，已登记的彩色图片保留原始色彩；颜色不能是唯一编码手段。
- 图内保留必要标签，细节放图注；不使用小到打印后不可读的文字。
- 图号在导出文件名中固定，例如 `fig_4_1_uart_sequence`，避免后续插图错位。
