# 图形制作规则

## 图形选型

| 需求 | 首选 | 源文件 | 导出物 |
| --- | --- | --- | --- |
| 控制流程、蓝牙命令状态、串口交互时序 | Draw.io | `.drawio` | 嵌入 XML 的 `.svg` + `.png` |
| 模块、引脚、数据流、通信拓扑 | Draw.io | `.drawio` | 嵌入 XML 的 `.svg` + `.png` |
| 无 Draw.io 时的简洁流程/时序 | Mermaid | `.mmd` | `.svg` + `.png` |
| 无额外安装的结构关系图 | Graphviz | `.dot` | `.svg` + `.png` |
| PWM 阶跃、角度、速度、串口时间序列 | Matplotlib | `.py` + `.csv`/日志摘录 | `.svg` + `.png` |
| 照片上的接口或部件说明 | 原始图片 + 标注脚本/记录 | 原图 + 标注说明 | `.png` |

Draw.io 提供更适合 Word 报告修订的可编辑流程和结构图；Mermaid 适合 Git 友好的简洁过程和时序图；Graphviz 是当前零新增安装的拓扑回退；Matplotlib 只绘制具有明确数据来源的数值图。它们不能替代真实接线图、示波器波形或实测照片。完整的证据门与后端选择见 `figure-workflow.md`。

## 每幅图的交付合同

```text
图号：图 3-2
标题：蓝牙动作命令到舵机执行的数据流
类型：结构图 / 流程图 / 实测曲线 / 实物照片
源文件：figures/source/fig_3_2.mmd
导出文件：figures/export/fig_3_2.svg, fig_3_2.png
输入来源：代码模块路径、串口日志、用户提供照片...
图中事实状态：实测证据 / 用户确认 / 设计示意
图注允许得出的结论：
限制：
```

## 信号图最低要求

对 PWM、UART、姿态角或控制量，至少标明：横轴及单位、纵轴及单位、采样或估计方式、测试条件、数据文件或日志范围。若波形由算法模拟而非实测，图题必须写“仿真/示意”。

## 版式

- 优先 SVG/PDF 等矢量图；为 Word 兼容可同时提供 200–300 DPI PNG。
- 同一章节统一字体、线宽、颜色、箭头和图例；颜色不能是唯一编码手段。
- 图内保留必要标签，细节放图注；不使用小到打印后不可读的文字。
- 图号在导出文件名中固定，例如 `fig_4_1_uart_sequence`，避免后续插图错位。
