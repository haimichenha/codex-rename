# 报告到答辩 PPT 的衔接

PPT 技能中值得复用的是“先设计简报、后内容/证据/资产计划、再渲染质检”的方法，而不是把报告全文压缩到幻灯片中。该方法与 [presentation-skill](https://github.com/sirilsengolraj-source/presentation-skill) 的结构化工作区和渲染 QA 思路一致。

## 生成前提

- 报告对应章节已具有可核查的证据；
- 每一页只表达一个主结论；
- 图、数据和术语使用报告中的同一版本；
- 无法支持的结论保留为“下一步验证”，不移花接木。

## 建议页面骨架

1. 任务目标与约束；
2. 总体结构与接口；
3. 软件/控制流程；
4. 关键实验方法；
5. 结果图表或实物照片；
6. 问题、改进与结论。

每页在生成前记录：受众、单页结论、证据图号、讲解备注、需要的素材以及已知限制。完成后同样执行“导出/渲染—目视检查—修正”。
