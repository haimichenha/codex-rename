# 可选报告导入与单向交接

仅当用户提供了定稿报告、报告证据清单或桥接包时使用本文件。没有报告时跳过，不影响独立 PPT 制作。

## 可读输入

- 只读报告版本、图号、数据文件、资产清单、结论边界和已确认限制；
- 可读取桥接包中的 `claim_id`、`asset_id`、数据版本、条件、权属与可证明/不可证明范围；
- 报告图号可作为来源标签，但不能替代 Asset ID 或数据条件。

## 允许的派生

可裁切、调色、重排叙事、重绘可编辑拓扑/图表，并在 PPT 自身工作区生成派生产物。不得覆盖报告正文、原图、报告 manifest、交接包或实验数据。

## 发现缺口时

把疑问写入 `ppt-workspace/qa/questions-for-source.md`，例如缺少样本条件、图源或权属。不要把猜测自动写回报告，也不要把待验证事项升格成成果。
