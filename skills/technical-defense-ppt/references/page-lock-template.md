# 单页 PPT 锁定卡

在画每一页之前，先将下列卡片写入 `ppt-workspace/page-locks/Pxx.md`。页面锁定后再开始排版，避免反复更换素材、堆叠装饰或让图文争夺焦点。

```text
页面编号与标题：
页面类型：内容页 / 封面 / 章节转场
讲述结论（可在 15 秒内说清）：
结论等级：已验证 / 受控任务验证 / 架构复用 / 应用设想 / 待验证
必须说明的边界：
对应原始证据 ID / 数据版本 / 可选报告图号：
转场豁免（仅封面/章节转场可填写）：可省略 Support 的原因；仍需写明主视觉是可追溯证据还是明确标注的情境材料，以及 Finish 的功能。

Hero 主证据：Asset ID、文件、精确裁切、视觉占比（通常 35%—60%）、图注
Support 支撑层：Asset ID、不同材料/不同裁切、作用、视觉占比
Finish 收尾层：标尺/图注轨/纹理/坐标/档案片段/色调底，服务的目的（定位/框定/节奏/深度）
正式图/表：源文件、数据范围、单位、证据状态
图像组合：彩色图（原始实物/实测/明确标注的生成解释）及其证据状态；黑白流程树/拓扑源文件；两者分别回答的问题
修饰元素预算：最多两类 Finish（例如页码轨 + 裁切框/测量刻度）；不允许遮挡读数、证据图或主结论

视觉模式：实物档案 / 纪录片分栏 / 技术拓扑 / 验证仪表 / 视频舞台 / 编辑式结论
纸面底色、深色板、中性字、强调色的角色：
网格、安全区、阅读方向与是否允许全出血背景：
相邻页区别：
讲解节拍与预计秒数：
Q&A 追问与可回指证据：
```

常规内容页未指定 Hero、Support、Finish 或结论边界时，不进入制作；封面/章节转场只有在已写明豁免、主视觉证据等级和 Finish 功能时才可省略 Support。“一张图加一列文字”不是默认页面结构。
