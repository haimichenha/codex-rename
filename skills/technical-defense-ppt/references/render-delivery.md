# PPT 渲染与交付规则

1. 用户给出的 `.pptx`、照片、日志和视频只读保留在 `ppt-workspace/input/`，记录名称、大小、修改时间和哈希；从版本化副本开始编辑。
2. 每个交付版本在 `ppt-workspace/output/` 中命名为 `deck-vN.pptx` 或等效版本号；不覆盖输入。
3. 每次修改后导出单页渲染图与 `contact-sheet.png` 到 `ppt-workspace/render/`，检查截字、越界、图片裁切、对比度、图例、跨页对齐和相邻页节奏。
4. 视频准备主片段、2—4 个关键帧和无法播放时的静态备份；讲述节拍、数据来源和可能追问写入 `notes/`。
5. 无法渲染或不能确认投影可读性时，在 `qa/` 标注待检项，不能假设版式已正确。
