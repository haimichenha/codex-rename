# PPT 独立证据边界

本规则只服务 PPT 页面，不要求先存在 Word 报告。每个会影响结论的素材都必须登记 Asset ID、来源、证据状态、数据版本、条件和可证明/不可证明范围。

## 证据等级

| 等级 | 可以写什么 | 不可以写什么 |
| --- | --- | --- |
| 实测证据 | 在明确条件下观察到的数值、日志、照片或视频事实 | 超出样本/条件的普适性能 |
| 用户确认 | 用户明确说明的分工、过程或状态 | 未给出的参数、成功率或因果结论 |
| 推导/设计解释 | 软件结构、接口、流程、计算或方案 | 已完成的实车闭环、验收或性能提升 |
| 情境/解释素材 | 氛围、概念、背景和非实测示意 | 项目实物、实测结果或现场部署 |

## 页面规则

1. 每页结论必须回链至少一个 Asset ID 或用户确认；定量结论还要写单位、条件、样本或数据范围。
2. 只有汇总统计而没有原始样本时，只能使用指标卡、统计表和条件说明；不得造出时序、直方图、误差带或前后提升曲线。
3. 不同设备、时段或条件的数值不可用同一坐标/大小并列暗示可比性；裁切无关瞬时读数，或明确标注不可直接比较。
4. 外部图片、生成图、概念图和装饰纹理必须标明情境/解释身份，不能压过项目证据。
5. 导入报告时，报告版本和图号只是可选来源字段；PPT 不得修改报告结论、数值、来源、权属或原始素材。
